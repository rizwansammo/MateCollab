# MateCollab Violet Logo Library

Approved direction: C, Violet. This package uses one precise vector master with four equal sharp L corners and a centered square. The selected raster concept has been rebuilt as clean symmetric geometry for scalable exports.

Primary Violet: #7047D1. Navy: #101A2D. White: #FFFFFF.

## Contents

* icons: transparent violet, white and black, plus light, dark, violet and dark violet backgrounds. Square, rounded and circular background shapes. The actual logo always keeps sharp corners.
* PNG sizes: 16, 20, 24, 32, 48, 64, 96, 128, 180, 192, 256, 384, 512, 1024 and 2048 pixels.
* JPG sizes: 512, 1024 and 2048 pixels for background variants. JPG cannot store transparency. Rounded and circular JPG edges are flattened to their background color; use PNG or SVG to retain shaped transparent corners.
* SVG: editable vector polygons. All lockup lettering is outlined from the supplied HemiHead Bold font, so font installation is not required.
* lockups: full MateCollab horizontal logo in six color treatments, SVG and PNG at 1024, 2048 and 4096 pixel width. Opaque versions also have JPG.
* favicons: SVG, multiple resolution ICO, 180px Apple touch icon, 192px and 512px app icons, and a web manifest.
* Use 256px or 512px square or rounded PNG files for avatars.

## Usage

Use the Violet icon on white and the white icon on navy or Violet for highest clarity. Dark violet is an optional decorative treatment; prefer white for very small dark UI icons. Keep at least one arm thickness of clear space around the visible mark. Do not stretch, rotate individual parts, round the logo geometry or add shadows. Use normal readable sans serif for application UI; HemiHead is for branding only.

The square background app exports include 10 percent padding on each side, leaving clear space around the mark. These are standard app icons, not maskable icons. Source SVG exports scale to any required print or display size.
